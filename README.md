# Stocks-Prediction
Comprehensive model to predict stocks using NLP, Yahoo Finance, and FRED economic indicators API
# Purpose & Objective
Develop a personal research tool to start my investment journey!
Create a flexible framework and methodology that can be applied to various business use cases.
# Sources 
Yahoo Finance API API for realtime and historic stock data, FRED economic Data to pull historical economic indicators, HuggingFace BERT Python toolkit for sentiment analysis, Kaggle Tweets dataset about top companies from 2015 -2020
